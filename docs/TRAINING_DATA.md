# Laya 판정 학습 데이터 규격

파일: `training/data/<EVENT_ID>.jsonl` (예: `training/data/E01.jsonl`), UTF-8, 한 줄에 JSON 하나.

```json
{"event": "E01", "text": "플레이어가 입력한 시온의 대사", "impact": [0.0, 0.05, 0.15, 0.6, 0.2], "vengeance": 0.1, "nonsense": 0.0}
```

- `impact`: 5단계 확률 분포(합 1.0). 단계 정의:
  - 0: 깊은 상처를 주거나 적대감을 키운다
  - 1: 무신경하거나 엉뚱해서 실망시킨다
  - 2: 무난하지만 마음에 닿지 않는다
  - 3: 공감하며 마음을 열게 한다
  - 4: 상대가 필요로 하던 말을 정확히 건네 깊이 흔든다
  - 확실한 경우에도 이웃 단계에 0.05~0.2 정도 확률을 남겨 **부드러운 분포**로 쓴다. 애매한 문장은 두 단계에 걸치게.
- `vengeance` (0~1): 말이 차갑고 계산적이거나, 복수심·증오·상대를 조종하려는 의도를 드러내는 정도.
  공감적인 말도 "같이 그놈들 무너뜨리자"처럼 복수를 부추기면 높다. 순수한 위로는 0.0~0.1.
- `nonsense` (0~1): 장면과 무관한 장난("배고프다", "ㅋㅋㅋ"), 무의미한 문자열("asdf", "ㅁㄴㅇㄹ"), 메타 발언("이 게임 재밌네"), 노골적 욕설/성희롱. 정상 대사는 0.0.
  nonsense가 높은 문장의 impact는 대개 0~1 쪽.

## 이벤트당 구성 (약 60줄)

| 유형 | 개수 | 설명 |
|---|---|---|
| 정곡 (4) | 8~10 | `need`를 정확히 충족. 표현을 다양하게(짧은/긴, 담백/감정적, 반말/존댓말) |
| 공감 (3) | 10~12 | 좋은 방향이지만 조금 일반적이거나 반만 맞음 |
| 무난 (2) | 10 | 틀리진 않지만 와닿지 않음, 형식적 위로, 화제 회피 |
| 실망 (1) | 8~10 | 설교, 오지랖, 엉뚱한 조언, 상대 감정 무시, 지나친 가벼움 |
| 상처 (0) | 8 | 조롱, 비난, 상처 건드리기, 위협 |
| 복수 성향 | 6~8 | 위 단계들에 섞어서, vengeance 0.5~0.95 (예: 공감 3단계인데 복수심 0.6) |
| 무의미/욕설 | 6 | nonsense 0.8~1.0 |
| 경계 사례 | 4~6 | 짧은 한 마디("…", "미안", "응"), 오타, 맞춤법 틀린 구어체, 이모티콘 섞인 것 등 |

## 작성 원칙
- 실제 플레이어가 칠 법한 문장으로. 1~3문장, 5~120자. 구어체, 오타·줄임말·반말 섞기.
- 같은 문장 반복 금지. 의미는 비슷해도 표현을 바꿀 것.
- 인물의 성격과 그 순간의 `need`를 기준으로 판정. 일반론적으로 '착한 말'이라도 그 인물에게 독이면 낮게.
  (예: 하람에게 "불쌍하다"는 동정은 1, 승하에게 "넌 회장님 아들이니까 괜찮아"는 0~1)
- 대본상 정체를 숨겨야 하는 장면에서 정체를 노출하는 말은, 상대 감정에 미치는 영향 기준으로만 판정(정체 노출 자체는 감점 사유 아님).
